# Mi Portfolio

**Autor:** Pablo Ruiz

Este proyecto es un portfolio personal desarrollado con HTML para mostrar información sobre mí y mis proyectos.

## Web

[Visitar mi portfolio](https://pabloo-ruiiz.github.io/portfolio/)

## Despliegue

El despliegue se realiza mediante GitHub Actions.

El workflow se ejecuta automáticamente cuando se realiza un `push` sobre la rama `main`. También puede ejecutarse manualmente mediante `workflow_dispatch`.

GitHub Actions ejecuta las tareas necesarias para empaquetar y publicar los archivos del proyecto en GitHub Pages.

## Workflow

El archivo de configuración del workflow se encuentra en:

`.github/workflows/static.yml`
